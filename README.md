# MoneyUp · 前进带薪仓鼠

MoneyUp 是一款本地优先的 Chrome 工位陪伴插件，把上班时间转换为看得见、听得见的分笔到账，向钱，向上！

## v0.6.6 特性

- 网页仓鼠总开关默认打开；完成引导或打开弹窗时申请一次显示权限，无需再去设置里专门开启
- 「今日战报」更名为「今日前进」：三套卡片（上进 / 摸鱼 / 极简），切换模板自动换文案
- 金额默认隐藏，可选手动展示今日已到账；下载 PNG 或一键复制文案
- 本机战报夹：分享过的卡片只存在这台浏览器，可回看
- 收工后首页出现轻提示，引导生成今日前进

## v0.6.1 特性

- 工具栏弹窗与网页仓鼠设置面板统一为 380px 宽
- 网页仓鼠内嵌设置可滚动，内容超出一屏时不再被裁切
- 卡片进账：`+金额` 从总金额右侧出现，飞入仓鼠身体后渐隐
- 仓鼠眨眼：约 4.2 秒一次，闭合相约 100ms，贴近自发眨眼节奏

## v0.6.0 特性

- 新品牌「前进 MoneyUp」，品牌定调「向钱，向上」，统一文案与动效体系
- 删除愿望胶囊功能，保持简洁专注
- 删除带薪时刻功能，简化设置
- 到账动效：`+XX 元` 从弹窗右上角飞入总金额，总金额按数字翻动结算
- 到账声音：金币碰撞入库，素材来自耳聆网 [支付宝到账金币掉落收钱音](https://www.ear0.com/sound/show/soundid-35919)（CC-BY，署名 L488386791；周期≥1 分钟且未静音时播放）
- 文案简化：首页显示「下一笔，X秒后到账」
- 设置页优化：币种选择与工资输入并排，更好的布局
- 新用户随机匹配：心跳到账（约8秒）或30分钟到账

## 本地安装

1. 打开 `chrome://extensions/`
2. 开启右上角“开发者模式”
3. 选择“加载已解压的扩展程序”
4. 选择本项目根目录（`manifest.json` 所在目录）
5. 按首次引导设置工资和工时；网页仓鼠默认开启，按 Chrome 提示授权一次即可

## 权限

- `storage`：在浏览器本地保存设置
- `scripting`：在用户授权后动态注册网页仓鼠
- `<all_urls>`：可选权限，仅用于在网页角落显示仓鼠，不读取、记录或上传网页内容
