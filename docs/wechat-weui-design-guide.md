# 微信小程序 / WeUI 设计与交互规范

> 版本：1.0  
> 研究日期：2026-09-01  
> 适用项目：Money Go（钱进 / 前进）、Money Way（前路 / 钱路）、Chrome 插件、后续微信小程序

## 1. 研究范围与一手资料

本规范以微信官方与腾讯官方开源资料为主，不以第三方 UI 模板作为标准。

- [微信小程序官方设计指南](https://developers.weixin.qq.com/miniprogram/design/)
- [Tencent / WeUI](https://github.com/Tencent/weui)：微信官方设计团队为微信 Web 服务设计的 UI 库。
- [Tencent / WeUI for 小程序](https://github.com/Tencent/weui-wxss)：包含 button、cell、dialog、progress、toast、actionsheet、icon 等官方风格元素，并支持深色模式。
- [WeUI-Design](https://github.com/weui/WeUI-Design)：微信官方基础视觉样式库与设计源文件。
- [WeUI 官方颜色变量](https://github.com/Tencent/weui-wxss/blob/master/dist/style/base/variable/color.wxss)
- [WeUI 官方 Button 样式](https://github.com/Tencent/weui/blob/master/src/style/widget/weui-button/weui-button.less)
- [WeUI 官方在线示例](https://weui.io/)

> 边界：“参考微信”是复用已被用户熟悉的信息层级、组件逻辑与操作反馈，不复制微信 Logo、气泡图形、特有插画或商标。

## 2. 四项核心原则

### 2.1 友好礼貌

- 每个页面仅有一个主任务，删除与当前目标无关的入口。
- 不用强制弹窗、连续红点、伪倒计时、诱导分享等方式抢占注意力。
- 请求敏感权限前说清“为什么需要”“会做什么”“不会做什么”“如何关闭”。
- 文案平等、简短、无说教感，让产品像工具和陪伴者，不像推销员。

### 2.2 清晰明确

- 导航始终回答：我在哪里、可以去哪里、怎么返回。
- 标题描述当前页面，按钮文案描述点击后的结果，不使用模糊的“好”“确定”。
- 状态不只依赖颜色；重要状态同时使用文字、图标或形状。
- 数字、币种、估算值与真实工资单边界必须明确。

### 2.3 便捷优雅

- 减少输入：优先使用预设、分段选择、开关和选择器。
- 主操作保持在稳定位置；不因内容动态变化而跳动。
- 操作后立即给予反馈：按下态、保存状态、成功 Toast、失败原因和恢复方法。
- 可逆操作优先直接执行；不可逆操作使用明确的二次确认。

### 2.4 统一稳定

- 相同任务使用同一组件、位置、名称和操作结果。
- 优先复用 WeUI 的 Cell、Button、Switch、Dialog、Toast、Progress 模型。
- 空状态、加载、错误、禁用和成功必须有完整样式，不只设计正常状态。
- 亮色 / 深色主题必须基于 token 切换，不在组件内硬编码颜色。

## 3. 视觉 Token

### 3.1 颜色

| Token | 亮色值 | 用途 |
|---|---:|---|
| `--brand` | `#07C160` | 主按钮、当前状态、成功、重点数字 |
| `--brand-pressed` | `#059A4C` | 主按钮按下态 |
| `--link` | `#576B95` | 文字链接、次级导航 |
| `--warn` | `#FA5151` | 破坏性操作、错误 |
| `--orange` | `#FA9D3B` | 提醒、假期 |
| `--yellow` | `#FFC300` | 金币、进度高光（小面积） |
| `--bg-0` | `#EDEDED` | 应用背景 |
| `--bg-1` | `#F7F7F7` | 次级区块 |
| `--bg-2` | `#FFFFFF` | Cell / Card / Dialog |
| `--fg-0` | `rgba(0,0,0,.90)` | 标题、主数据 |
| `--fg-1` | `rgba(0,0,0,.55)` | 正文、说明 |
| `--fg-2` | `rgba(0,0,0,.30)` | 占位、弱辅助文字 |
| `--separator` | `rgba(0,0,0,.10)` | 分割线、边界 |
| `--pressed` | `rgba(0,0,0,.10)` | 按下状态遮罩 |

以上取自 WeUI 现行官方变量。Money Go 可使用微信绿作为 UI 主色，但品牌图形不使用微信气泡轮廓。

### 3.2 字体和字号

字体栈：

```css
font-family: -apple-system, BlinkMacSystemFont, "Helvetica Neue",
  "PingFang SC", "Noto Sans CJK SC", "Microsoft YaHei", Arial, sans-serif;
```

| 层级 | Chrome 弹窗 | 小程序建议 | 字重 |
|---|---:|---:|---:|
| 核心金额 | 36–40 px | 36–40 px | 600–700 |
| 页面标题 | 17–20 px | 20 px | 600 |
| Cell 主标题 | 14–16 px | 17 px | 400–500 |
| 正文 | 13–14 px | 16 px | 400 |
| 辅助文字 | 11–12 px | 14 px | 400 |
| 极弱说明 | 不小于 10 px | 不小于 12 px | 400 |

金额使用等宽数字 `font-variant-numeric: tabular-nums`，避免数字跳动导致布局抖动。

### 3.3 间距、圆角、阴影

- 基础间距：4 px；常用序列：`4 / 8 / 12 / 16 / 24 / 32 / 48`。
- 页面左右安全边距：16 px；窄弹窗最小 12 px。
- Cell 高度：48–56 px；可点区域不小于 44×44 px。
- 圆角：小元素 4 px，按钮 8 px，卡片 12 px，弹层 12–16 px。不默认使用“全员药丸化”。
- 默认用背景层级和 1 px 分割线表达容器；阴影仅用于浮层、网页挂件和 Dialog。

## 4. 组件规范

### 4.1 Button

- 主按钮：绿底白字，每页最多一个。高 48 px，圆角 8 px，文字 16–17 px。
- 次按钮：白底 / 浅灰底，黑字，边界使用 separator。
- 小按钮：32 px 高，14 px 字号，6 px 圆角。
- 破坏性操作：不与主按钮使用相同强度；使用红色文字或二次确认。
- 加载中禁止重复点击，文案变为具体状态，如“正在保存…”。

### 4.2 Cell / 列表

- 设置页优先使用分组 Cell，不使用多张彩色卡片。
- 左侧是图标 / 标题，右侧是当前值 / Switch / 箭头。
- 分割线从文字起始位开始，不穿过左侧图标。
- 二级说明放在主标题下方，使用 `fg-1`，不与可点标题竞争。

### 4.3 表单

- 标签永远可见，不仅靠 placeholder 解释字段。
- 币种和单位不与标签拆成多个 flex 文本节点。
- 数字输入设置合理的 `min`、`max`、`step`，错误就地显示。
- 保存可以即时生效，但必须有“已保存”的短反馈。

### 4.4 反馈

- Toast：轻量成功 / 失败，1.5–2 秒后消失，不承载需要阅读的长文。
- Dialog：仅用于不可逆操作、权限说明和重要决策。
- Loading：超过 400 ms 的操作显示；超过 10 s 提供取消 / 重试。
- 空状态：一句说明 + 一个主操作，不用大量营销文案。

## 5. 导航与交互

- 顶部栏使用稳定的返回、标题和右侧操作位；标题居中时，左右占位宽度对称。
- 弹窗首页是摘要，设置、愿望、分享是二级页，不再嵌套第三层。
- 网页挂件鼠标移入展开，移出收起；键盘 Enter / Space 打开，Esc 返回。
- 设置入口的命名、图标和结果在网页挂件与弹窗中保持一致。
- 操作区分隔不小于 8 px，主要与次要操作必须有强弱层级。

## 6. 无障碍与适配

- 所有图标按钮提供 `aria-label`；装饰图形使用 `aria-hidden="true"`。
- 键盘焦点可见，焦点顺序与视觉顺序一致。
- 普通文字对比度目标不低于 4.5:1，大字不低于 3:1。
- 支持 `prefers-reduced-motion`；金币动效在减少动效模式下只渐隐。
- 中文、英文、长币种文本和 80%–200% 缩放下不裁切主操作。
- 小程序页面使用安全区和系统导航栏参数，不自己猜测状态栏高度。

## 7. Money Go / Money Way 落地决策

| 原有表达 | 新规范 |
|---|---|
| 奶油黄大面积背景 | WeUI `#EDEDED / #F7F7F7` 中性背景 |
| 红色主按钮 | 微信绿 `#07C160` 主按钮 |
| 多种高饱和彩色卡片 | 白色分组 Cell + 小面积语义色 |
| 全局大圆角 + 阴影 | 8–12 px 克制圆角 + 1 px 分割线 |
| 设置页密集小字 | Cell 分组，主字号 14–16 px，辅助不小于 11 px |
| 装饰性动效 | 仅保留仓鼠状态和到账反馈 |
| 多种主色争夺注意力 | 绿色主操作，黄色金币，红色只做错误 |

## 8. 验收清单

- [ ] 首屏 3 秒内可识别今日金额、进度和下班时间。
- [ ] 每页不超过一个高强度主操作。
- [ ] 所有设置有当前值、可点状态和保存反馈。
- [ ] 没有只靠红 / 绿区分的状态。
- [ ] 键盘、减少动效、中英文长文本和缩放验证通过。
- [ ] 无远程字体、远程图标或运行时 UI 依赖。
- [ ] 不使用微信 Logo、气泡商标或对腾讯设计源文件的未授权再分发。
